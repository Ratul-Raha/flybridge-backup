Landing Page Build Brief: Easy & Smart IELTS Reading
Project goal
Build a high-converting program landing page for Easy & Smart IELTS
Reading, part of the Easy & Smart course series by FlyBridge.

This page should feel like a sibling to the existing Easy & Smart
English landing page: visitors should immediately recognize the shared
series identity, visual language, and product quality. However, do
not duplicate the previous page section-for-section or simply swap
the copy. Give IELTS Reading its own visual rhythm, layout variations,
and subject-specific personality.

The page must communicate one clear promise:
Learn practical IELTS Reading skills and question-solving strategies
in 40 days, with just 20 minutes of learning per day.

The design should feel modern, focused, confident, educational, and
conversion-oriented.
1. Brand and design direction
Series identity
- Treat Easy & Smart as the umbrella series brand.
- Use a consistent series lockup, such as:
  - EASY & SMART
  - IELTS READING as the specific program name
- The existing Easy & Smart English page and this page should look
  like two products from the same family.
- Reuse the established typography, color palette, button style,
  border radius, spacing scale, icon style, and general visual quality
  from the existing page wherever appropriate.
- Do not make the pages identical. Shared brand elements should create
  recognition; section compositions and visual storytelling should
  create distinction.
IELTS Reading's visual personality
Use visual cues associated with reading, comprehension, scanning,
evidence, and time management:
- Highlighted text, underlined keywords, passage snippets, answer
  markers, question cards, page indicators, and subtle
  reading-progress motifs.
- Consider a refined editorial / study-workspace aesthetic rather than
  generic education illustrations.
- A visual showing a passage being scanned and relevant keywords being
  identified could work well in the hero or preview area.
- Use real course preview imagery/video if available. Do not fabricate
  a video thumbnail or claim that a preview video exists if no asset
  is supplied.
Overall style
- Minimal, clean, premium, and easy to scan.
- Strong typography and clear hierarchy.
- Generous whitespace; avoid clutter and excessive decorative
  elements.
- Use subtle gradients or soft background surfaces only if they align
  with the existing Easy & Smart page.
- Avoid generic AI-looking hero compositions, childish illustrations,
  excessive floating cards, and unnecessary animations.
- Mobile-first responsive layout. The page must feel intentionally
  designed on small screens, not merely compressed.

typographic refinements are acceptable, but do not rewrite the core
message or change numerical claims.

3. Conversion and interaction requirements
- The primary hero CTA and closing CTA should lead to the same course
  enrollment / purchase action used by the existing Easy & Smart
  course page.
- If the project already has a shared CTA component or checkout flow,
  reuse it.
- Preserve existing authentication, checkout, and enrollment behavior.
  Do not create a parallel flow.
- The "40 VIDEOS · 20 MIN/DAY" badge is informational unless a real
  preview interaction is connected.
- If a preview video is supplied, use the existing video modal/player
  behavior. Do not create a non-functional play button.
- Ensure all interactive elements have visible hover, focus, active,
  and disabled states where relevant.
4. Responsive behavior
Desktop
- Use a balanced content width and strong section spacing.
- Avoid overly wide paragraphs.
- Keep the hero composition visually engaging without overpowering the
  headline.
- Use multi-column layouts where they improve scanning and comparison.
Tablet
- Reduce grid columns naturally.
- Keep card spacing and typography balanced.
- Avoid awkward wrapping in Bengali and English mixed-language
  headings.
Mobile
- Stack hero content and visual cleanly.
- Keep CTA buttons comfortably tappable and preferably full-width
  where appropriate.
- Convert feature and metric grids to layouts that remain readable.
- Ensure Bengali text has sufficient line height.
- Avoid horizontal overflow, clipped badges, and tiny curriculum text.
5. Accessibility and implementation quality
- Use semantic section headings in a logical order.
- Maintain accessible color contrast.
- Provide meaningful alt text for informative images and empty alt
  text for purely decorative visuals.
- Ensure keyboard navigation and visible focus states.
- Use buttons for actions and links for navigation.
- Respect reduced-motion preferences.
- Optimize images and video previews for performance.
- Avoid layout shifts while media loads; reserve the required aspect
  ratio or dimensions.
- Use the project's existing design system, components, and
  conventions before introducing new dependencies.
6. Technical instructions for the coding agent
1. First inspect the existing Easy & Smart English landing page and
   identify its reusable design tokens, components, CTA behavior,
   responsive breakpoints, and page conventions.
2. Inspect the current routing and enrollment flow. Reuse the existing
   implementation.
3. Build Easy & Smart IELTS Reading as a distinct page within the
   same Easy & Smart series.
4. Maintain shared series branding, but vary section layouts and visual
   storytelling so the two pages are related rather than duplicated.
5. Use the exact supplied copy and figures. Do not invent claims,
   course features, lesson counts per phase, testimonials, ratings, or
   preview assets.
6. Reuse existing icon libraries and UI components where possible.
   Avoid adding dependencies for decorative elements.
7. Test the completed page at desktop, tablet, and mobile widths.
8. Check Bengali typography, mixed Bengali-English line wrapping, CTA
   behavior, and all responsive states.
9. Do not modify the existing Easy & Smart English page unless a shared
   component needs a safe, backward-compatible improvement.
10. Before finishing, provide a concise summary of the files changed and
    any assets or content still needed from the project owner.
7. Final design test
The finished page should pass these checks:
- A visitor can immediately identify this as an Easy & Smart
  series program.
- A visitor can immediately identify this specific program as IELTS
  Reading.
- The 40-day, 40-video, 20-minute-per-day proposition is clear.
- The four pillars --- Skills, Strategy, Practice, Familiarity --- are
  visually connected.
- The page feels related to Easy & Smart English but does not look
  like a duplicate.
- The supplied Bengali copy remains accurate and readable.
- Both primary CTAs work with the existing enrollment flow.
- The page is polished and usable on mobile.
